# Hospital Management Analytics Dashboard

An interactive healthcare analytics dashboard built to analyze patient, appointment, billing, treatment, and revenue data.

## Features
- Patient Demographics Analysis
- Appointment Status Tracking
- Revenue & Billing Insights
- Treatment Analysis
- Doctor Performance Monitoring
- Interactive Charts and Visualizations
- AI-Inspired Analytics Dashboard Design

- Jupyter Notebook
- HTML
- CSS
- JavaScript
- Chart.js

- Claude AI
